# Gakk 3D Particle Logo Header

Interactive 3D particle canvas featuring the exact Gakk logo geometry with 5,000 dots, #666666 dot color, and real-time cursor blow-out physics.

## 🚀 Instant Deployment to Vercel

### Option 1: Vercel Dashboard (Zero Config)
1. Extract this `.zip` and upload or push the folder to a GitHub repository.
2. Go to [Vercel](https://vercel.com/new).
3. Select your repository and click **Deploy**. Vercel will instantly serve the static site globally.

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel
```

## 📦 Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: Gakk 3D Particle Logo Header"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

## 🛠 Local Preview
Run any local static server:
```bash
npx serve .
```
or double-click `index.html` in your browser.
